1. L’idée générale

Un service Web permet à un programme, le client, de demander une opération ou des données à un autre programme, le serveur, via un réseau.

Client → demande → serveur → résultat → client

Les notions à distinguer

RESTStyle qui utilise les méthodes HTTP et des URL. Réponse souvent en JSON.
SOAPRègles pour échanger des messages de service, généralement écrits en XML.
XMLFormat structuré avec des balises qui nomment les données.
WSDLDescription d’un service SOAP : opérations, paramètres et résultats.
RPCDemander à un serveur distant d’exécuter une fonction et renvoyer son résultat.
RMIMécanisme Java pour appeler les méthodes d’un objet distant.

Mémo : RPC est le principe d’un appel distant ; RMI est une façon Java de le faire ; SOAP transporte des messages XML ; WSDL explique comment appeler le service.

2. REST : requête et réponse

GET https://api.exemple.com/pays?nom=France
  • GET : méthode HTTP pour lire une ressource.
  • https : protocole ; api.exemple.com : serveur.
  • /pays : ressource ; ? commence les paramètres.
  • & sépare plusieurs paramètres. La réponse est souvent en JSON.

Codes : 200 = succès ; 404 = ressource introuvable. Vérifier le code avant d’utiliser la réponse.

3. SOAP : étapes et code

  1. L’interface déclare les opérations.
  2. L’implémentation contient le traitement.
  3. Le serveur publie le service.
  4. Le client lit le WSDL, appelle une opération et reçoit le résultat.

Déclarer les opérations

@WebService
public interface StringService {
    @WebMethod
    String reverse(String chaine);

    @WebMethod
    int length(String chaine);
}

@WebService marque le service ; @WebMethod marque une opération accessible au client. Le type avant le nom est le type retourné.

Implémenter une opération

public String reverse(String chaine) {
    if (chaine == null) return "";
    return new StringBuilder(chaine).reverse().toString();
}

public int length(String chaine) {
    if (chaine == null) return 0;
    return chaine.length();
}

reverse("salut") renvoie "tulas" ; length("salut") renvoie 5.

Publier et appeler

// Serveur Java
Endpoint.publish(
    "http://localhost:8081/StringService",
    new StringServiceImpl()
);

# Client Python
client = Client("http://localhost:8081/StringService?wsdl")
resultat = client.service.reverse("salut")

SOAP transporte la demande et la réponse. WSDL décrit les opérations, les paramètres et les résultats attendus.

4. RMI et RPC

RMI — Java distant

public interface Calculatrice extends Remote {
    int add(int a, int b) throws RemoteException;
}

public class CalculatriceImpl
        extends UnicastRemoteObject
        implements Calculatrice {
    public int add(int a, int b) throws RemoteException {
        return a + b;
    }
}

// Le client appelle l'objet distant
calculatrice.add(10, 20);

Le serveur enregistre l’objet dans le registre RMI ; le client le recherche par son nom. Le TP utilise le port 1099. Une RemoteException signale qu’un appel distant peut échouer.

XML-RPC — appel de fonction à distance

// Client Python : ressemble à un appel local,
// mais la fonction s’exécute sur le serveur distant.
serveur.Calcul.addition(a, b)

Le serveur associe le nom Calcul à une classe de service, puis le client demande l’exécution d’une méthode. Le résultat revient au client.

5. Code Java sur les chaînes

Compter les voyelles

public int countVowels(String chaine) {
    if (chaine == null) return 0;

    int compteur = 0;
    for (int i = 0; i < chaine.length(); i++) {
        char lettre = Character.toLowerCase(
            chaine.charAt(i)
        );
        if ("aeiou".indexOf(lettre) >= 0) {
            compteur++;
        }
    }
    return compteur;
}

countVowels("Salut") renvoie 2.

Vérifier un palindrome

public boolean isPalindrome(String chaine) {
    if (chaine == null) return false;

    String texte = chaine.replaceAll("\\s+", "")
                         .toLowerCase();
    String inverse = new StringBuilder(texte)
                         .reverse().toString();
    return texte.equals(inverse);
}

Cette version ignore les espaces et la casse : "Radar" donne true, "salut" donne false.

Opérations utiles

chaine.length();                         // longueur

chaine.toLowerCase();                    // minuscules

6. Questions probables et pièges

Qu’est-ce que SOAP ? Un protocole pour échanger des messages de service, généralement en XML.

À quoi sert WSDL ? À décrire les opérations, paramètres et résultats d’un service SOAP.

Qu’est-ce que RPC ? Le client demande au serveur distant d’exécuter une fonction et de renvoyer le résultat.

Différence RMI / RPC ? RPC est le principe général ; RMI est le mécanisme Java d’appel de méthodes d’objets distants.

Comment le client reçoit-il le résultat SOAP ? Le serveur exécute l’opération et renvoie le résultat dans une réponse SOAP.

Dans une URL REST, que signifient ? et & ? Début des paramètres, puis séparation entre paramètres.

Pièges de syntaxe Java

  • Écrire String avec une majuscule.
  • Lire un caractère avec chaine.charAt(i), pas chaine[i].
  • Dans une boucle, écrire i < chaine.length(), pas i <= chaine.length().
  • Comparer les chaînes avec .equals(), pas ==.
  • Créer un inverse avec new StringBuilder(chaine).
Pour le code : commence par la signature (type retourné, nom et paramètres), écris le traitement, puis le return. Pense aux chaînes vides, aux majuscules, aux espaces et à null si l’énoncé le demande.
